# OYONO DATA & IA

Portfolio professionnel de François Oyono : ingénierie structures, Data Analysis et IA générative.

Site public : https://francois-oyono.github.io/portfolio-btp-data/

## Consulter et modifier les sources

Ouvrez ce dossier dans VS Code :
- `index.html` : contenu, rubriques et liens.
- `style.css` : présentation et affichage mobile.
- `script.js` : onglets, filtres, fiches projets et formulaire e-mail.
- `assets/logo.webp` : logo OYONO DATA & IA.

Pour consulter une copie locale, ouvrez `index.html` dans votre navigateur.
Le site statique ne nécessite aucune installation de dépendances.

## Publication

GitHub Pages publie la branche `main` depuis la racine du dépôt.
Les mises à jour de cette branche déclenchent le déploiement du site.
Le fichier `.nojekyll` permet de servir directement les fichiers statiques.

## Projets et données

Les projets sont présentés avec leur état d'avancement. Le studio d'agents IA est une démonstration locale à partir d'exemples pré-rédigés : aucun modèle IA n'est appelé et aucun contenu n'est publié sur les réseaux sociaux.
Le formulaire de contact prépare un brouillon dans la messagerie du visiteur. Il ne transmet ni ne conserve les champs sur le site.
Aucun rapport Power BI ou jeu de données client n'est embarqué.

Version publique mise à jour le 5 novembre 2026, avec les liens YouTube et LinkedIn confirmés par François Oyono.
